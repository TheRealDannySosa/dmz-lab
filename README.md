# Laboratorio: Implementación de una DMZ Segura

Este repositorio contiene la solución al laboratorio de configuración de una Zona Desmilitarizada (DMZ) utilizando Cisco Packet Tracer.

## Contenido del Repositorio
- `DMZ_PROJECT.pkt`: Archivo con la topología y configuración final del ejercicio.
- `informe/Informe_DMZ_Laboratorio.md`: Informe técnico detallado con la arquitectura, plan de IP, ACLs y pruebas de verificación.
- `evidencias/`: Capturas de pantalla que respaldan el correcto funcionamiento de las reglas de seguridad.# dmz-lab
